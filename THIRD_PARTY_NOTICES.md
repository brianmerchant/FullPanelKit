## 1. Third-party material included in this distribution

**None.** No third-party source code, binaries, fonts or other assets that
carry their own license terms are included. Checked on 2026-10-19 against
the exact release tree:

- The Swift package (`Package.swift`) declares no dependencies, and there is
  no `Package.resolved`.
- `Integrations/*/Cargo.lock` and `Integrations/Electron/package-lock.json`
  are dependency pins generated by Cargo and npm. They list dependencies but
  contain none of their code.
- The integration test applications' HTML, CSS, JavaScript and
  `tauri.conf.json` are FullPanelKit's own. The Tauri test icon
  (`Integrations/Tauri/test-app/icons/icon.png`, 32 × 32) is a plain
  placeholder made for this project.
- The images in `docs/evidence/` are screen captures from FullPanelKit's
  own test runs.
- No file carries a third-party copyright notice or license header.

## 3. Platform interfaces

FullPanelKit calls Apple's macOS frameworks (AppKit, Foundation,
CoreGraphics, the Objective-C runtime) and, at runtime, private AppKit
methods and SkyLight functions that it looks up by name. It includes no
Apple source code, and these frameworks are part of macOS, not bundled
dependencies. Private class, selector, symbol and type-encoding names, and
the constants such interfaces require, are interoperability facts. Their
use is not supported by Apple and may break with any macOS update
([docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)).

The two SkyLight constants in `FPKMenuBarOverlay.m` (a Space mask and the
fullscreen Space type) were cross-checked against public reverse-engineered
headers (CGSInternal; [yabai](https://github.com/asmvik/yabai), MIT). No code
from either was copied.
